## NEW GAPS FOUND

PRD AC says "selection persists across reload" for filter view, and "switching never writes task data." But the Persistence section only defines the `'todo-demo:tasks'` key. FilterView has per-filter empty messages. FullApp line 161 uses a flat "Nothing to show here." for all filters. The composite should match the feature-component behavior it claims to demonstrate.
